# CivicFix

CivicFix is a full-stack civic issue reporting and resolution platform.

## Tech Stack

### Frontend
- React.js
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- TypeScript

### Database
- MySQL
- Sequelize ORM

### Authentication
- JWT
- Access Token
- Refresh Token
- bcrypt

### Other Technologies
- Cloudinary
- Leaflet
- OpenStreetMap
- Postman
- Jest
- Supertest
- GitHub
